# How to cite

If you use this library in your research, please cite the
[PyTorch Metric Learning paper](https://arxiv.org/abs/2008.09164):

```bibtex
@article{Musgrave2020PyTorchML,
  title={PyTorch Metric Learning},
  author={Kevin Musgrave and Serge J. Belongie and Ser-Nam Lim},
  journal={ArXiv},
  year={2020},
  volume={abs/2008.09164}
}
```

GitHub also reads the repository's
[`CITATION.cff`](https://github.com/KevinMusgrave/pytorch-metric-learning/blob/master/CITATION.cff).
Please also cite the paper of each loss, miner, or sampler you use; every
component page links its paper.

# 3.0.0rc3

This is the third release candidate for version 3.0.0. It changes defaults and
sampler behavior that are easier to change before the final release. The
[3.0.0rc1 notes](3.0.0rc1.md) describe version 3 as a whole, and the
[migration guide](../migration-2-to-3.md) covers version 2 names.

## Changed defaults

- `DotProductSimilarity()` now computes a plain dot product. Pass
  `normalize_embeddings=True` for the previous behavior. `NPairsLoss` and
  `NormalizedSoftmaxLoss` request normalization explicitly, so their default
  objectives do not change
  ([#670](https://github.com/KevinMusgrave/pytorch-metric-learning/issues/670)).
- `TripletMarginLoss` now defaults to `margin=0.2`, matching
  `TripletMarginMiner` and FaceNet. Pass `margin=0.05` for the previous default
  ([#466](https://github.com/KevinMusgrave/pytorch-metric-learning/issues/466)).

## Documentation

- Recipe pages link to readable source on GitHub for the matching release
  instead of Python files that browsers download.
